# Винни

Русская адаптация хоррор-лендинга об умном доме.

Сайт: https://madvarz1337.github.io/Vinni/

Откройте `index.html` локально или используйте любой статический HTTP-сервер. Установка зависимостей и сборка не требуются.

Исходный проект Hearthly: https://jikol1906.github.io/Hearthly/

Автор оригинала и исходный код: https://github.com/jikol1906/Hearthly

Переведены интерфейс, динамические сообщения, журнал и финал. Используются локальные шрифты Manrope, Literata и IBM Plex Mono с поддержкой кириллицы; лицензии SIL OFL находятся в `fonts/`.

Форма не отправляет данные. Камера и наблюдение — графические эффекты. Звук синтезируется локально в браузере. Доступ к камере и микрофону не запрашивается.
